Mac Mouse Fix 3.1.0 Beta 1 trae un excelente nuevo sistema de traducción, que ha estado en desarrollo durante un tiempo.
También hay algunas mejoras en la interfaz.

¡Nuevo sistema de localización!

  • Ahora es muy fácil contribuir traducciones de alta calidad a Mac Mouse Fix, sin necesidad de conocimientos técnicos.
  • Hay muchas capturas de pantalla anotadas y comentarios, y una excelente función de búsqueda, para que los traductores puedan entender fácilmente cómo aparecen sus traducciones en la aplicación.
    • Creo que las capturas de pantalla y la interfaz de traducción (la app Xcloc Editor) son de la más alta calidad del mercado, ¡y espero que te ayuden a proporcionar excelentes traducciones!
  • Casi todas las partes del proyecto son traducibles ahora, incluyendo la ‘Guía de Botones Capturados’, el Readme de GitHub, el sitio web, y más.
    • Todas estas partes del proyecto se pueden traducir desde un lugar centralizado con referencias cruzadas fáciles usando la app Xcloc Editor, para que los traductores puedan mantener todo consistente fácilmente.
  • El sistema está configurado para ser muy fácil de mantener, así que a medida que Mac Mouse Fix evolucione y se añadan nuevas pantallas o textos, todo se actualizará automáticamente.
  • Aclaración: uso mucho la palabra ‘fácil’. Los flujos de trabajo son fáciles, pero pensar en excelentes traducciones sigue siendo, por supuesto, un trabajo arduo y respetable. Simplemente hay menos barreras en el camino ahora.

Otros cambios

Al usar Mac Mouse Fix en inglés, no ha cambiado mucho, pero se han actualizado algunas cosas en la interfaz, y mucho ha cambiado internamente para ayudar a mejorar las traducciones:

  • Aspecto refinado para las pequeñas notificaciones emergentes.
  • Tooltips y errores más claros en varios lugares.
  • La tecla escape ahora se puede usar en todas partes para cerrar notificaciones, hojas y ventanas emergentes.
  • Se ha añadido un enlace ‘Ayudar a Traducir’ en la pestaña Acerca de.
  • El ancho de las vistas y ventanas emergentes se ha ajustado para verse bien en varios idiomas.
  • Mejor disposición del texto para chino y coreano, que tenían problemas de ajuste de línea en algunas de las pequeñas notificaciones emergentes.
  • Se reemplazó la biblioteca de análisis de Markdown para corregir algunos errores de formato en chino y coreano.
  • Muchos más cambios y mejoras internos.
