Mac Mouse Fix 3.1.0 Beta 1 帶來了全新的翻譯系統，這個系統已經開發了一段時間。
同時也有一些介面改進。

全新本地化系統！

  • 現在為 Mac Mouse Fix 貢獻高品質翻譯變得超級簡單，完全不需要技術背景。
  • 有大量附註的截圖和說明，以及強大的搜尋功能，讓翻譯者可以輕鬆了解他們的翻譯在應用程式中的呈現方式。
    • 我認為這些截圖和翻譯介面（Xcloc Editor 應用程式）是市面上品質最高的，希望它們能幫助你提供出色的翻譯！
  • 現在幾乎所有專案部分都可以翻譯，包括「已捕捉按鈕指南」、GitHub Readme、網站等等。
    • 所有這些專案部分都可以透過 Xcloc Editor 應用程式在一個集中的地方進行翻譯，並且可以輕鬆交叉參照，讓翻譯者能夠保持一致性。
  • 這個系統設計得非常容易維護，所以當 Mac Mouse Fix 發展並新增新畫面或文字時，一切都會自動更新。
  • 免責聲明：我經常使用「簡單」這個詞。工作流程是簡單的，但想出優秀的翻譯當然仍然是一項艱辛且值得尊敬的工作！只是現在障礙變少了。

其他變更

使用英文版 Mac Mouse Fix 時，變化不大，但介面有一些更新，底層也有許多調整，以幫助改善翻譯：

  • 小型彈出通知的外觀更加精緻。
  • 各處的工具提示和錯誤訊息更加清晰。
  • 現在可以在任何地方使用 Escape 鍵來關閉通知、工作表和彈出視窗。
  • 在「關於」標籤頁中新增了「協助翻譯」連結。
  • 調整了視圖和彈出視窗的寬度，使其在各種語言中都能呈現良好效果。
  • 改善了中文和韓文的文字排版，這些語言在某些小型彈出通知中存在換行問題。
  • 更換了 Markdown 解析函式庫，以修復中文和韓文的一些格式錯誤。
  • 還有更多底層變更和改進。
