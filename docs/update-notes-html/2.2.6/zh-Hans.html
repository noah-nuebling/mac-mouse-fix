Mac Mouse Fix 2.2.6 添加了对 macOS 27 Golden Gate 的支持，并恢复了对旧版 macOS 的支持。

  • 现已支持 macOS 27 Golden Gate - 界面已更新，“调度中心与空间”手势恢复正常。
  • 重新支持 macOS 10.11 El Capitan 和 macOS 10.12 Sierra，这两个版本上次支持是在 MMF 2.2.0。Apple 的开发者工具并不正式支持这些版本，但似乎仍然可以正常工作。我还没有机会在旧版 macOS 上进行测试，如果有任何问题，请告诉我。
  • 更新了”更多…“及其他位置的部分链接。
  • 修复了一个小界面问题：即使”平滑滚动”已禁用，“滚动速度”滑块有时仍会处于启用状态。
