Mac Mouse Fix 2.2.6 新增對 macOS 27 Golden Gate 嘅支援，並恢復對舊版 macOS 嘅支援。

  • 現已支援 macOS 27 Golden Gate - 介面已更新，「Mission Control 同 Spaces」手勢再次正常運作。
  • 再次支援 macOS 10.11 El Capitan 同 macOS 10.12 Sierra，呢兩個版本上次獲支援係喺 MMF 2.2.0。Apple 嘅開發者工具並唔正式支援呢啲版本，但似乎仍然可以運作。我未有機會喺舊版 macOS 上測試，如果有任何問題，請話畀我知。
  • 更新咗「更多…」同其他地方嘅部分連結。
  • 修正咗一個小型介面錯誤，「捲動速度」滑桿有時會喺「平滑捲動」停用時仍然可用。
