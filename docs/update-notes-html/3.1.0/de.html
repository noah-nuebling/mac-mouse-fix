Mac Mouse Fix 3.1.0 behebt die Unterstützung für macOS 27 und fügt Übersetzungen hinzu.

Unterstützung für macOS 27 Golden Gate

Gesten wie „Spaces & Mission Control”, die auf der Simulation von 3-Finger-Trackpad-Wischgesten basieren, funktionieren unter macOS 27 Golden Gate wieder.
