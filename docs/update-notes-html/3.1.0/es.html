Mac Mouse Fix 3.1.0 corrige el soporte para macOS 27 y añade traducciones.

Soporte para macOS 27 Golden Gate

Los gestos como ‘Spaces y Mission Control’ que dependen de simular deslizamientos de trackpad con 3 dedos vuelven a funcionar en macOS 27 Golden Gate.
