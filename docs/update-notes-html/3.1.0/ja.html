Mac Mouse Fix 3.1.0 では macOS 27 のサポートを修正し、翻訳を追加しました。

macOS 27 Golden Gate のサポート

3本指トラックパッドスワイプのシミュレーションに依存する「操作スペースと Mission Control」などのジェスチャーが、macOS 27 Golden Gate で再び動作するようになりました。

翻訳

  • プロジェクトのほぼすべての部分が翻訳可能になりました。
  • 翻訳への貢献がより簡単になりました。
  • 「情報」タブに新しい「翻訳に協力する」ボタンが追加されました。
  • これに対応するため、UI とバックグラウンドに多くの変更が加えられました。
  • 詳しくは翻訳ガイドをご覧ください。
