Mac Mouse Fix 3.1.0 fikser støtte for macOS 27 og legger til oversettelser.

Støtte for macOS 27 Golden Gate

Bevegelser som ‘Spaces og Mission Control’ som er avhengige av å simulere 3-fingers styreflatesveip fungerer igjen under macOS 27 Golden Gate.

Oversettelser

  • Nesten alle deler av prosjektet kan nå oversettes.
  • Det er nå mye enklere å bidra med oversettelser.
  • Det er en ny ‘Hjelp til å oversette’-knapp på Om-fanen.
  • Mange UI- og bakgrunnsendringer for å tilrettelegge for dette.
  • For å lære mer, se Oversettelsesguiden.
