# 3.1.0
***Data de Lançamento:** 15 de set. de 2026*

<br>

Mac Mouse Fix **3.1.0** corrige o suporte para macOS 27 e adiciona traduções.

### Suporte para macOS 27 Golden Gate

Gestos como 'Spaces e Mission Control' que dependem da simulação de deslizes de 3 dedos no trackpad funcionam novamente no macOS 27 Golden Gate.

### Traduções

- Quase todas as partes do projeto agora podem ser traduzidas.
- Agora é muito mais fácil contribuir com traduções.
- Há um novo botão 'Ajudar a Traduzir' na aba Sobre.
- Muitas mudanças na interface e em segundo plano para acomodar isso.
- Para saber mais, veja o [Guia de Tradução](https://redirect.macmousefix.com/?target=mmf-localization-contribution&locale=pt-BR).
