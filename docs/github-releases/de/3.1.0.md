# 3.1.0
***Veröffentlichungsdatum:** 15.09.2026*

<br>

Mac Mouse Fix **3.1.0** behebt die Unterstützung für macOS 27 und fügt Übersetzungen hinzu.

### Unterstützung für macOS 27 Golden Gate

Gesten wie „Spaces & Mission Control", die auf der Simulation von 3-Finger-Trackpad-Wischgesten basieren, funktionieren unter macOS 27 Golden Gate wieder.

### Übersetzungen

- Fast alle Teile des Projekts sind jetzt übersetzbar.
- Es ist jetzt viel einfacher, Übersetzungen beizutragen.
- Es gibt einen neuen „Beim Übersetzen helfen"-Button im Über-Tab.
- Viele UI- und Hintergrundänderungen, um dies zu ermöglichen.
- Mehr dazu findest du im [Übersetzungsleitfaden](https://redirect.macmousefix.com/?target=mmf-localization-contribution&locale=de).
