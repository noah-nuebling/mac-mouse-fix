# 3.1.0
***Дата випуску:** 15 вер. 2026 р.*

<br>

Mac Mouse Fix **3.1.0** виправляє підтримку macOS 27 та додає переклади.

### Підтримка macOS 27 Golden Gate

Жести, такі як «Простори та Mission Control», які покладаються на симуляцію свайпів трьома пальцями по трекпаду, знову працюють у macOS 27 Golden Gate.

### Переклади

- Тепер майже всі частини проєкту можна перекладати.
- Тепер набагато легше долучитися до перекладу.
- На вкладці «Про програму» з'явилася нова кнопка «Допомогти з перекладом».
- Багато змін в інтерфейсі та у фоновому режимі для забезпечення цього.
- Щоб дізнатися більше, переглянь [Посібник з перекладу](https://redirect.macmousefix.com/?target=mmf-localization-contribution&locale=uk).
