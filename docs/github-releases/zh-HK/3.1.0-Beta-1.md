# 3.1.0 Beta 1
***發佈日期：** 2025年11月29日*

<br>

Mac Mouse Fix **3.1.0 Beta 1** 帶來全新嘅翻譯系統，呢個系統已經開發咗一段時間。\
另外仲有一啲介面改進。

### 全新本地化系統！

- 而家為 Mac Mouse Fix 貢獻高質素翻譯變得超級簡單，完全唔需要任何技術背景。
- 有大量附有註解嘅截圖同評論，仲有強大嘅搜尋功能，令翻譯者可以輕鬆了解佢哋嘅翻譯喺應用程式入面點樣顯示。
    - 我認為呢啲截圖同翻譯介面（`Xcloc Editor` 應用程式）係市面上最高質素嘅，希望可以幫助你提供出色嘅翻譯！
- 而家幾乎所有項目部分都可以翻譯，包括「已捕捉按鈕指南」、GitHub Readme、網站等等。
    - 所有呢啲項目部分都可以透過 `Xcloc Editor` 應用程式喺一個集中嘅地方進行翻譯，並且可以輕鬆交叉參考，令翻譯者可以保持一致性。
- 呢個系統設計得非常易於維護，所以當 Mac Mouse Fix 發展同加入新畫面或文字時，一切都會自動更新。
- 免責聲明：我用咗好多次「簡單」呢個詞。工作流程係簡單嘅，但諗出出色嘅翻譯當然仍然係好多辛苦同值得尊重嘅工作！只係而家少咗啲障礙。

### 其他變更

當使用英文版 Mac Mouse Fix 時，變化唔大，但介面有一啲更新，底層亦有好多改動，以幫助改善翻譯：

- 小型彈出通知嘅外觀更加精緻。
- 各處嘅工具提示同錯誤訊息更加清晰。
- 而家可以喺任何地方使用 Escape 鍵嚟關閉通知、表單同彈出視窗。
- 喺「關於」分頁加入咗「幫助翻譯」連結。
- 調整咗視圖同彈出視窗嘅寬度，令各種語言都顯示得好睇。
- 改善咗中文同韓文嘅文字排版，解決咗部分小型彈出通知嘅換行問題。
- 更換咗 Markdown 解析庫，修復咗中文同韓文嘅一啲格式錯誤。
- 仲有好多底層變更同改進。
