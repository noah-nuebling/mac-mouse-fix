# 3.1.0
***發佈日期：** 2026年9月15日*

<br>

Mac Mouse Fix **3.1.0** 修復咗 macOS 27 嘅支援同埋新增咗翻譯。

### 支援 macOS 27 Golden Gate

依賴模擬三指觸控板滑動嘅手勢，例如「空間同 Mission Control」，喺 macOS 27 Golden Gate 上面又可以正常運作喇。

### 翻譯

- 而家幾乎所有項目部分都可以翻譯。
- 而家貢獻翻譯變得更加容易。
- 喺「關於」分頁新增咗「幫助翻譯」按鈕。
- 為咗配合呢啲改動，介面同後台都做咗好多更改。
- 想了解更多，請睇 [翻譯指南](https://redirect.macmousefix.com/?target=mmf-localization-contribution&locale=zh-HK)。
