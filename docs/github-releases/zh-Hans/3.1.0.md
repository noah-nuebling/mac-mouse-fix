# 3.1.0
***发布日期：** 2026年9月15日*

<br>

Mac Mouse Fix **3.1.0** 修复了对 macOS 27 的支持并添加了翻译。

### 支持 macOS 27 Golden Gate

在 macOS 27 Golden Gate 下，依赖模拟三指触控板滑动的手势（如"调度中心和多桌面空间"）现已恢复正常工作。

### 翻译

- 项目的几乎所有部分现在都可以翻译了。
- 现在贡献翻译变得更加容易。
- 在"关于"标签页中新增了"帮助翻译"按钮。
- 为此进行了大量界面和后台更改。
- 了解更多信息，请参阅[翻译指南](https://redirect.macmousefix.com/?target=mmf-localization-contribution&locale=zh-Hans)。

### 其他

- 未放弃对任何 macOS 版本的支持。尽管 macOS 27 开发者工具不再正式支持 macOS 10.15 Catalina，本应用仍继续支持。
- Mac Mouse Fix 3.1.0 现在仅占用 15.4 MB，相比之前的 19.6 MB 有所减少。
