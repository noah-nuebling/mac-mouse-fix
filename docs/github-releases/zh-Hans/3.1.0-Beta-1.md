# 3.1.0 Beta 1
***发布日期：** 2025年11月29日*

<br>

Mac Mouse Fix **3.1.0 Beta 1** 带来了全新的翻译系统，这个系统已经开发了一段时间。\
同时还有一些界面改进。

### 全新本地化系统！

- 现在为 Mac Mouse Fix 贡献高质量翻译变得超级简单，完全不需要任何技术背景。
- 提供了大量带注释的截图和说明，以及强大的搜索功能，让翻译者可以轻松了解他们的翻译在应用中的实际显示效果。
    - 我认为这些截图和翻译界面（`Xcloc Editor` 应用）是市面上最高质量的，希望它们能帮助你提供出色的翻译！
- 现在项目的几乎所有部分都可以翻译了，包括"捕获按钮指南"、GitHub Readme、网站等等。
    - 所有这些项目部分都可以通过 `Xcloc Editor` 应用在一个集中的地方进行翻译，并且可以轻松交叉引用，方便翻译者保持一致性。
- 这个系统的设计非常易于维护，所以随着 Mac Mouse Fix 的发展和新界面或文本的添加，一切都会自动更新。
- 声明：我用了很多次"简单"这个词。工作流程确实简单，但想出优秀的翻译当然仍然是一项艰辛且值得尊敬的工作！只是现在障碍更少了。

### 其他更改

使用英文版 Mac Mouse Fix 时，变化不大，但界面有一些更新，底层也有很多调整，以帮助改进翻译效果：

- 优化了小型弹出通知的外观。
- 多处工具提示和错误信息更加清晰。
- 现在可以在任何地方使用 Escape 键关闭通知、表单和弹出窗口。
- 在"关于"标签页中添加了"帮助翻译"链接。
- 调整了视图和弹出窗口的宽度，使其在各种语言中都能呈现良好效果。
- 改进了中文和韩文的文本布局，解决了部分小型弹出通知中的换行问题。
- 更换了 Markdown 解析库，修复了中文和韩文的一些格式问题。
- 还有更多底层的更改和改进。
