# 3.1.0
***發布日期：** 2026年9月15日*

<br>

Mac Mouse Fix **3.1.0** 修復了對 macOS 27 的支援並新增了翻譯。

### 支援 macOS 27 Golden Gate

依賴模擬三指觸控板滑動的手勢（如「空間與調度中心」）現在在 macOS 27 Golden Gate 上可以正常運作了。

### 翻譯

- 專案的幾乎所有部分現在都可以翻譯了。
- 現在貢獻翻譯變得更加容易。
- 「關於」標籤頁新增了「協助翻譯」按鈕。
- 為此進行了大量的介面和後台變更。
- 如需了解更多，請參閱[翻譯指南](https://redirect.macmousefix.com/?target=mmf-localization-contribution&locale=zh-Hant)。
