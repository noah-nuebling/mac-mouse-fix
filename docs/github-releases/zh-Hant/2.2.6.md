# 2.2.6
***發布日期：** 2026年10月3日*

<br>

Mac Mouse Fix **2.2.6** 新增對 **macOS 27 Golden Gate** 的支援，並恢復對舊版 macOS 的支援。

- 現已支援 **macOS 27 Golden Gate** - 介面已更新，「Mission Control 與空間」手勢再次正常運作。
- 再次支援 **macOS 10.11 El Capitan** 和 **macOS 10.12 Sierra**，這兩個版本上次支援是在 MMF 2.2.0。Apple 的開發者工具並未正式支援這些版本，但似乎仍可正常運作。我還沒有機會在舊版 macOS 上測試，如果有任何問題，請告訴我。
- 更新了「更多...」及其他位置的部分連結。
- 修正了一個小型介面錯誤，「捲動速度」滑桿有時會在「平滑捲動」停用時仍處於啟用狀態。
