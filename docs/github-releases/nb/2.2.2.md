# 2.2.2
***Utgivelsesdato:** 23. okt. 2022*

<br>

Den **forrige utgivelsen** [**2.2.1**](https://redirect.macmousefix.com/?target=mmf-release&tag=2.2.1&locale=nb) la til støtte for **macOS 13 Ventura** og mer!

---

Mac Mouse Fix **2.2.2** inneholder flere **små rettelser** og forbedringer.

### Tilgjengelighetsproblemer

2.2.2 løser et problem der "Mac Mouse Fix Helper" ikke kunne få **tilgangstillatelse** i Systeminnstillinger etter oppdatering fra Mac Mouse Fix 2.2.0 eller tidligere. Se GitHub Issue [#412](https://github.com/noah-nuebling/mac-mouse-fix/issues/412).

### Feilrettinger

- Fikset et problem der **varsler** forsvant brått i stedet for å tone ut med en animasjon under macOS Ventura
- Fikset en feil der **lenker** på "Mer..."-skjermen og "Gi tilgangstillatelse"-skjermen noen ganger åpnet seg om og om igjen når du klikket hvor som helst i Mac Mouse Fix-vinduet

### Andre forbedringer

- Forbedret **UI-tekster** på "Gi tilgangstillatelse"-skjermen
- Forbedringer **under panseret**
