# 2.2.1 Beta 3
***Utgivelsesdato:** 6. sep. 2022*

<br>

Mac Mouse Fix __2.2.1 Beta 3__ bringer tilbake kompatibilitet med eldre macOS-versjoner og mer.

- Fikset krasj ved oppstart under eldre macOS-versjoner. Bør løse problem [#327](https://github.com/noah-nuebling/mac-mouse-fix/issues/327).
- Fikset en krasj når man prøver å legge til apper som ikke har et appnavn i appspesifikke innstillinger. Bør løse problem [#241](https://github.com/noah-nuebling/mac-mouse-fix/issues/241). Spesiell takk til [jeongtae](https://github.com/jeongtae) som var veldig hjelpsom med å finne ut av problemet!
- Flere små feilrettinger og forbedringer under panseret.
