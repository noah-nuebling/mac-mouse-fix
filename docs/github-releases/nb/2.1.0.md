# 2.1.0
***Utgivelsesdato:** 9. jan. 2022*

<br>


Sjekk også ut de **kule tingene** introdusert i [Mac Mouse Fix 2](https://redirect.macmousefix.com/?target=mmf-release&tag=2.0.0&locale=nb)!

---

### Appen fungerer igjen.

Jeg signerte appen med et nytt sertifikat. Det gamle sertifikatet ble tilbakekalt av Apple, noe som gjør gamle versjoner av Mac Mouse Fix ubrukelige. Se [dette innlegget](https://github.com/noah-nuebling/mac-mouse-fix/discussions/114) for mer info.

### Ny funksjon!

Du kan nå kontrollere **medieavspilling**, **høyttalervolum**, **skjermlysstyrke** og mer rett fra musen din! 
Dette er mulig fordi Mac Mouse Fix nå lar deg tilordne museknappene dine til hvilken som helst tast på tastaturet – til og med Apples proprietære funksjonstaster som «Spill av/pause» eller «Demp høyttaler».
