# 2.2.1 Beta 1
***Utgivelsesdato:** 5. aug. 2022*

<br>

### Ventura-støtte!
Mac Mouse Fix støtter nå fullt ut macOS 13 Ventura.
Spesiell takk til [@chamburr](https://github.com/chamburr) som hjalp med Ventura-støtte i GitHub Issue [#297](https://github.com/noah-nuebling/mac-mouse-fix/issues/297).

### Droppet støtte for eldre macOS-versjoner

Dessverre lar Apple deg bare utvikle _for_ macOS 10.13 **High Sierra og nyere** når du utvikler _fra_ macOS 13 Ventura.

Så **minimum støttet versjon** har økt fra 10.11 El Capitan til 10.13 High Sierra.

Beklager dette. Men for å muntre deg opp er det en avslappet marihøne i neste seksjon.

### Feilrettinger 🐞 
- Fikset en krasj i '**App-spesifikke innstillinger**' når man prøvde å legge til en app uten en 'Bundle ID'. Kan hjelpe med GitHub Issues [#289](https://github.com/noah-nuebling/mac-mouse-fix/issues/289) og [#241](https://github.com/noah-nuebling/mac-mouse-fix/issues/241).
- Fikset et problem der Mac Mouse Fix endret rulleoppførselen til noen **tegnebrett**. Se GitHub Issue [#249](https://github.com/noah-nuebling/mac-mouse-fix/issues/249).
- Fikset et problem der **tastatursnarveier** som inkluderte 'A'-tasten ikke kunne registreres. Fikser GitHub Issue [#275](https://github.com/noah-nuebling/mac-mouse-fix/issues/275).
- Fikset et problem der noen knapp-**omtilordninger** ikke fungerte ordentlig ved bruk av et ikke-standard tastaturoppsett.
- **Andre** små rettinger og visuelle forbedringer.
