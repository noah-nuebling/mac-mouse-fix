# 2.2.6
***Utgivelsesdato:** 3. okt. 2026*

<br>

Mac Mouse Fix **2.2.6** legger til støtte for **macOS 27 Golden Gate** og bringer tilbake støtte for eldre macOS-versjoner.

- Støtter nå **macOS 27 Golden Gate** - Brukergrensesnittet er oppdatert og «Mission Control & Spaces»-bevegelsen fungerer igjen.
- Støtter **macOS 10.11 El Capitan** og **macOS 10.12 Sierra** igjen, som sist ble støttet i MMF 2.2.0. Apples utviklerverktøy støtter ikke dette offisielt, men det ser ut til å fungere likevel. Jeg har ikke hatt mulighet til å teste på eldre macOS-versjoner, så gi meg beskjed hvis det er noen problemer.
- Oppdatert noen av lenkene under «Mer...» og andre steder.
- Fikset en liten feil i brukergrensesnittet der «Rullehastighet»-glidebryteren noen ganger var aktivert selv om «Jevn rulling» er deaktivert.
