# 3.1.0
***출시일:** 2026. 9. 15.*

<br>

Mac Mouse Fix **3.1.0**은 macOS 27 지원을 수정하고 번역을 추가합니다.

### macOS 27 Golden Gate 지원

macOS 27 Golden Gate에서 세 손가락 트랙패드 스와이프 시뮬레이션에 의존하는 'Spaces 및 Mission Control' 같은 제스처가 다시 작동합니다.

### 번역

- 이제 프로젝트의 거의 모든 부분을 번역할 수 있습니다.
- 번역에 기여하기가 훨씬 쉬워졌습니다.
- 정보 탭에 새로운 '번역 돕기' 버튼이 추가되었습니다.
- 이를 위한 많은 UI 및 백그라운드 변경이 있었습니다.
- 자세한 내용은 [번역 가이드](https://redirect.macmousefix.com/?target=mmf-localization-contribution&locale=ko)를 참조하세요.
