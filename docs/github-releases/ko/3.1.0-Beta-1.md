# 3.1.0 Beta 1
***출시일:** 2025. 11. 29.*

<br>

Mac Mouse Fix **3.1.0 Beta 1**은 오랫동안 준비해 온 훌륭한 새 번역 시스템을 제공해.\
UI 개선 사항도 있어.

### 새로운 현지화 시스템! 

- 이제 기술적 배경 지식 없이도 Mac Mouse Fix에 고품질 번역을 기여하는 것이 매우 쉬워졌어.
- 주석이 달린 스크린샷과 코멘트가 많고, 훌륭한 검색 기능이 있어서 번역자들이 자신의 번역이 앱에서 어떻게 표시되는지 정확히 이해할 수 있어.
    - 스크린샷과 번역 UI(`Xcloc Editor` 앱)가 시장에서 최고 품질이라고 생각하며, 훌륭한 번역을 제공하는 데 도움이 되길 바라!
- 이제 '캡처된 버튼 가이드', GitHub Readme, 웹사이트 등 프로젝트의 거의 모든 부분을 번역할 수 있어.
    - 이 모든 프로젝트 부분을 `Xcloc Editor` 앱을 사용하여 한 곳에서 쉽게 상호 참조하며 번역할 수 있어서, 번역자들이 모든 것을 일관되게 유지하기 쉬워.
- 시스템은 유지 관리가 매우 쉽도록 설정되어 있어서, Mac Mouse Fix가 발전하고 새로운 화면이나 텍스트가 추가되면 모든 것이 자동으로 업데이트돼.
- 참고: '쉽다'라는 단어를 많이 사용했어. 워크플로우는 쉽지만, 훌륭한 번역을 생각해내는 것은 물론 여전히 많은 노력과 존경받을 만한 작업이야! 이제 방해물이 줄어들었을 뿐이야.

### 기타 변경 사항 

Mac Mouse Fix를 영어로 사용할 때는 크게 변경된 것이 없지만, UI에서 몇 가지가 업데이트되었고, 번역을 더 좋게 만들기 위해 내부적으로 많은 것이 변경되었어:

- 작은 팝업 알림의 모양이 개선되었어.
- 여러 곳에서 툴팁과 오류 메시지가 더 명확해졌어.
- 이제 어디서든 ESC 키를 사용하여 알림, 시트, 팝업을 닫을 수 있어.
- 정보 탭에 '번역 도움주기' 링크가 추가되었어.
- 다양한 언어에서 보기 좋게 뷰와 팝업의 너비가 조정되었어.
- 일부 작은 팝업 알림에서 텍스트 줄바꿈 문제가 있던 중국어와 한국어의 텍스트 레이아웃이 개선되었어.
- 중국어와 한국어의 일부 서식 버그를 수정하기 위해 Markdown 파싱 라이브러리를 교체했어.
- 더 많은 내부 변경 사항과 개선 사항이 있어.
