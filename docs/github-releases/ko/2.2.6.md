# 2.2.6
***출시일:** 2026. 10. 3.*

<br>

Mac Mouse Fix **2.2.6**은 **macOS 27 Golden Gate** 지원을 추가하고 이전 macOS 버전에 대한 지원을 복원합니다.

- 이제 **macOS 27 Golden Gate**를 지원합니다 - UI가 업데이트되었고 'Mission Control & Spaces' 제스처가 다시 작동합니다.
- MMF 2.2.0에서 마지막으로 지원되었던 **macOS 10.11 El Capitan**과 **macOS 10.12 Sierra**를 다시 지원합니다. Apple의 개발자 도구가 공식적으로 지원하지는 않지만 여전히 작동하는 것 같습니다. 이전 macOS 버전에서 테스트할 기회가 없었으니, 문제가 있으면 알려주세요.
- '더 보기...' 및 기타 위치의 일부 링크를 업데이트했습니다.
- '부드러운 스크롤'이 비활성화되어 있어도 '스크롤 속도' 슬라이더가 활성화되는 작은 UI 버그를 수정했습니다.
