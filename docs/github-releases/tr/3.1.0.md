# 3.1.0
***Yayın Tarihi:** 15 Eyl 2026*

<br>

Mac Mouse Fix **3.1.0** macOS 27 desteğini düzeltiyor ve çeviriler ekliyor.

### macOS 27 Golden Gate Desteği

macOS 27 Golden Gate altında 3 parmak izleme dörtgeni kaydırmalarını simüle eden 'Spaces & Mission Control' gibi hareketler tekrar çalışıyor.

### Çeviriler

- Projenin neredeyse tüm bölümleri artık çevrilebilir.
- Çevirilere katkıda bulunmak artık çok daha kolay.
- Hakkında sekmesinde yeni bir 'Çeviriye Yardım Et' butonu var.
- Bunu karşılamak için birçok arayüz ve arka plan değişikliği yapıldı.
