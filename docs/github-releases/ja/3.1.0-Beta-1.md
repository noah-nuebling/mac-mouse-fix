# 3.1.0 Beta 1
***リリース日:** 2025/11/29*

<br>

Mac Mouse Fix **3.1.0 Beta 1** では、しばらく開発を進めてきた素晴らしい新しい翻訳システムが導入されました。\
また、UIの改善もいくつか行われています。

### 新しいローカライゼーションシステム！

- 技術的な知識がなくても、Mac Mouse Fixの高品質な翻訳に簡単に貢献できるようになりました。
- 注釈付きのスクリーンショットやコメントが豊富にあり、優れた検索機能も備わっているため、翻訳者は自分の翻訳がアプリ内でどのように表示されるかを正確に理解できます。
    - スクリーンショットと翻訳UI（`Xcloc Editor`アプリ）は市場で最高品質だと思っており、素晴らしい翻訳の提供に役立つことを願っています！
- 「キャプチャされたボタンガイド」、GitHub Readme、ウェブサイトなど、プロジェクトのほぼすべての部分が翻訳可能になりました。
    - これらすべての部分は、`Xcloc Editor`アプリを使用して一元化された場所から翻訳でき、簡単に相互参照できるため、翻訳者は一貫性を保ちやすくなっています。
- このシステムはメンテナンスが非常に簡単になるように設計されているため、Mac Mouse Fixが進化し、新しい画面やテキストが追加されても、すべてが自動的に更新されます。
- 注意：「簡単」という言葉をよく使っていますが、ワークフローは簡単でも、素晴らしい翻訳を考えることはもちろん大変で尊敬に値する作業です！ただ、障壁が少なくなっただけです。

### その他の変更

Mac Mouse Fixを英語で使用している場合、大きな変更はありませんが、UIでいくつかの更新があり、翻訳をより良くするために内部で多くの変更が行われました：

- 小さなポップアップ通知の外観を改良しました。
- 様々な場所でツールチップとエラーメッセージをより明確にしました。
- エスケープキーを使用して、通知、シート、ポップアップをどこでも閉じられるようになりました。
- 「翻訳を手伝う」リンクが「情報」タブに追加されました。
- ビューとポップアップの幅が、様々な言語で美しく表示されるように調整されました。
- 一部の小さなポップアップ通知でテキストの折り返しに問題があった中国語と韓国語のテキストレイアウトを改善しました。
- 中国語と韓国語での一部のフォーマットバグを修正するため、Markdownパースライブラリを置き換えました。
- その他多くの内部変更と改善。
