# 2.2.6
***リリース日:** 2026/10/03*

<br>

Mac Mouse Fix **2.2.6** は **macOS 27 Golden Gate** のサポートを追加し、古いmacOSバージョンのサポートを復活させました。

- **macOS 27 Golden Gate** をサポート - UIが更新され、「Mission Control & Spaces」ジェスチャーが再び動作するようになりました。
- MMF 2.2.0で最後にサポートされていた **macOS 10.11 El Capitan** と **macOS 10.12 Sierra** を再びサポート。Appleの開発者ツールは公式にはサポートしていませんが、動作するようです。古いmacOSバージョンでのテストはできていないので、問題があれば教えてください。
- 「その他...」やその他の場所のリンクを更新しました。
- 「スムーズスクロール」が無効になっているにもかかわらず、「スクロール速度」スライダーが有効になることがある小さなUIバグを修正しました。
