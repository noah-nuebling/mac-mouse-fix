# 3.1.0
***Fecha de lanzamiento:** 15 sept 2026*

<br>

Mac Mouse Fix **3.1.0** corrige el soporte para macOS 27 y añade traducciones.

### Soporte para macOS 27 Golden Gate

Los gestos como 'Spaces y Mission Control' que dependen de simular deslizamientos de trackpad con 3 dedos vuelven a funcionar en macOS 27 Golden Gate.

### Traducciones

- Casi todas las partes del proyecto ahora son traducibles.
- Ahora es mucho más fácil contribuir con traducciones.
- Hay un nuevo botón 'Ayudar a Traducir' en la pestaña Acerca de.
- Muchos cambios en la interfaz y en segundo plano para acomodar esto.
- Para más información, consulta la [Guía de Traducción](https://redirect.macmousefix.com/?target=mmf-localization-contribution&locale=es).
