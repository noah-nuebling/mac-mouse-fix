# 3.1.0 Beta 1
***Дата выпуска:** 29 нояб. 2025 г.*

<br>

Mac Mouse Fix **3.1.0 Beta 1** представляет отличную новую систему перевода, над которой велась работа уже некоторое время.\
Также есть некоторые улучшения интерфейса.

### Новая система локализации! 

- Теперь очень легко вносить качественные переводы в Mac Mouse Fix, без какого-либо технического опыта.
- Есть множество аннотированных скриншотов и комментариев, а также отличная функция поиска, чтобы переводчики могли легко понять, как именно их переводы отображаются в приложении.
    - Я считаю, что скриншоты и интерфейс перевода (приложение `Xcloc Editor`) — лучшие на рынке, и надеюсь, что они помогут тебе создавать отличные переводы!
- Почти все части проекта теперь можно переводить, включая «Руководство по захваченным кнопкам», GitHub Readme, веб-сайт и многое другое.
    - Все эти части проекта можно переводить из одного централизованного места с удобными перекрёстными ссылками с помощью приложения `Xcloc Editor`, что позволяет переводчикам легко поддерживать согласованность.
- Система настроена так, чтобы её было очень легко поддерживать, поэтому по мере развития Mac Mouse Fix и добавления новых экранов или текстов всё будет обновляться автоматически.
- Оговорка: я часто использую слово «легко». Рабочие процессы легки, но придумывание отличных переводов — это, конечно, всё ещё много тяжёлой и уважаемой работы! Просто теперь меньше препятствий на пути.

### Другие изменения 

При использовании Mac Mouse Fix на английском языке мало что изменилось, но некоторые элементы интерфейса были обновлены, и многое изменилось под капотом, чтобы улучшить переводы:

- Улучшенный внешний вид маленьких всплывающих уведомлений.
- Более понятные подсказки и сообщения об ошибках в различных местах.
- Клавиша Escape теперь может использоваться везде для закрытия уведомлений, листов и всплывающих окон.
- Ссылка «Помочь с переводом» добавлена на вкладку «О программе».
- Ширина окон и всплывающих элементов была скорректирована для хорошего отображения на разных языках.
- Улучшена компоновка текста для китайского и корейского языков, у которых были проблемы с переносом строк в некоторых маленьких всплывающих уведомлениях.
- Заменена библиотека парсинга Markdown для исправления некоторых ошибок форматирования в китайском и корейском языках.
- Множество других изменений и улучшений под капотом.
