# 3.1.0
***Дата выпуска:** 15 сент. 2026 г.*

<br>

Mac Mouse Fix **3.1.0** исправляет поддержку macOS 27 и добавляет переводы.

### Поддержка macOS 27 Golden Gate

Жесты, такие как «Spaces и Mission Control», которые используют симуляцию свайпов тремя пальцами по трекпаду, снова работают в macOS 27 Golden Gate.

### Переводы

- Почти все части проекта теперь можно переводить.
- Теперь гораздо проще вносить вклад в переводы.
- На вкладке «О программе» появилась новая кнопка «Помочь с переводом».
- Множество изменений в интерфейсе и внутренней работе для поддержки этого.
- Подробнее см. в [Руководстве по переводу](https://redirect.macmousefix.com/?target=mmf-localization-contribution&locale=ru).

- Mac Mouse Fix 3.1.0 теперь занимает всего 15,4 МБ вместо 19,6 МБ.
