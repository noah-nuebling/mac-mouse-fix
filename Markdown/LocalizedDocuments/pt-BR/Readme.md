<a name="installation"></a>
## Instalação

Baixe a versão mais recente do Mac Mouse Fix no [site](https://macmousefix.com/).

Você também pode instalar o Mac Mouse Fix via [Homebrew](https://brew.sh/)! Basta digitar o seguinte comando no terminal:


<a name="macos-compatibility"></a>
## Compatibilidade com macOS

A versão mais recente do Mac Mouse Fix foi desenvolvida para **macOS 11 Big Sur** ou superior.

Se você estiver usando macOS **10.15 Catalina**, macOS **10.14 Mojave** ou macOS **10.13 High Sierra**, pode utilizar a [versão mais recente do Mac Mouse Fix 2](https://redirect.macmousefix.com/?locale=pt-BR&target=mmf2-latest). O Mac Mouse Fix 3.0.0 e versões posteriores ainda podem funcionar na sua máquina, mas podem apresentar problemas visuais e algumas funcionalidades podem não funcionar corretamente.

Se você estiver usando macOS **10.12 Sierra** ou **10.11 El Capitan**, pode utilizar o Mac Mouse Fix [2.2.0](https://github.com/noah-nuebling/mac-mouse-fix/releases/tag/2.2.0) ou versões anteriores.

<a name="uninstallation"></a> 
## Desinstalação

Para desinstalar o Mac Mouse Fix, basta movê-lo para a lixeira.

No entanto, alguns arquivos permanecerão no sistema. Para removê-los completamente, recomendo o excelente [AppCleaner da FreeMacSoft](https://freemacsoft.net/appcleaner/).

No macOS, não é possível que os próprios aplicativos removam esses arquivos residuais automaticamente ao serem excluídos. Por isso, recomendo fortemente o uso de um app como o AppCleaner.

<a name="tips"></a> 
## Dicas

- **Gerencie janelas com um simples clique e arrastar**


  O [Swish](https://highlyopinionated.co/swish/) é a minha forma favorita de gerenciar janelas no macOS. Com um simples gesto no trackpad, ele permite posicionar qualquer janela para ocupar metade, um quarto ou a tela inteira.
  
  O Swish foi projetado para gestos no trackpad, mas com o Mac Mouse Fix você pode usá-lo com qualquer mouse de terceiros! Basta ir até o Mac Mouse Fix e configurar a ação **"Clique e Arrastar"** de qualquer botão como **"Rolar e Navegar"** — assim, você poderá encaixar janelas com um simples clique e arrastar.
  
  Tudo o que você pode fazer com um gesto de dois dedos no trackpad da Apple também funciona perfeitamente com o recurso **"Rolar e Navegar"** do Mac Mouse Fix.
  

- **Controle o brilho da tela, o volume do áudio ou a reprodução de mídia diretamente pelo mouse**


  O Mac Mouse Fix permite que você use **qualquer tecla do teclado** diretamente pelo mouse -  
  inclusive teclas especiais encontradas apenas nos teclados da Apple, que permitem controlar o brilho da tela, o volume do áudio, a reprodução de mídia e muito mais.
  
  Se você não tiver um teclado da Apple à mão, **segure a tecla Option (⌥)** para escolher as teclas especiais da Apple.

## Perguntas


- **O Mac Mouse Fix é nativo no Apple Silicon?**
    
  Sim, o Mac Mouse Fix roda 100% de forma nativa no Apple Silicon.
  

- **Por que há um atraso quando eu clico?**


  Quando você clica, o Mac Mouse Fix pode aguardar para verificar se você vai dar um duplo clique.<br>
  Para remover esse atraso em um botão, exclua qualquer ação de **"Duplo Clique"** associada a ele.

- **Meu mouse é compatível?**


  Provavelmente sim. Para ter certeza, o melhor é baixar o Mac Mouse Fix e testá-lo.
  
  O Mac Mouse Fix funciona muito bem com a maioria dos mouses. No entanto, em alguns modelos projetados para funcionar com softwares proprietários, como o Logitech Options, o Mac Mouse Fix ainda não consegue reconhecer todos os botões.
  
  Isso acontece porque esses mouses se comunicam com o computador usando um protocolo proprietário especial, em vez do protocolo USB padrão.<br>
  Eu adoraria adicionar compatibilidade completa com esses mouses no futuro, mas isso exige muito trabalho e não deve acontecer tão cedo.

  Se quiser **ajudar na tradução do projeto**, veja o [Guia de Tradução](https://redirect.macmousefix.com/?target=mmf-localization-contribution).<br>
  Se quiser **reportar traduções ausentes ou ruins**, isso também ajuda. A melhor forma é comentar no [Guia de Tradução](https://redirect.macmousefix.com/?target=mmf-localization-contribution).

- **Contribuir com código**

  Se quiser contribuir com código, ótimo! Vou ficar feliz com qualquer [pull request](https://github.com/noah-nuebling/mac-mouse-fix/pulls).
  
  No entanto, talvez eu não aceite todas. Para garantir que seu trabalho não seja perdido, você pode abrir primeiro um pull request descrevendo as mudanças que pretende fazer, com pouco ou nenhum código. Assim posso dar feedback e dizer se adotaria as mudanças desse jeito.

**Obrigado** a todos que já contribuíram e me apoiaram na missão de criar o melhor driver de mouse *de todos os tempos*! :)🚀
