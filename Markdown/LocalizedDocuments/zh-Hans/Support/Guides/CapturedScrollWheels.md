# 被捕获的滚轮

与[捕获鼠标按键](<../../Support/Guides/CapturedButtonsMMF3.md>)的机制类似，Mac Mouse Fix **在默认情况下会捕获鼠标的滚轮**。

**若要防止滚轮被捕获：**

1. 进入 Mac Mouse Fix 的“滚动”标签页
2. 关闭**所有**选项
    - 针对“速度”选项，将其设置为“macOS”
    - 点击每个修饰键旁边的“x”按钮，删除“键盘修饰键”下的所有条目

完成这些操作后，你应该会看到一条提示，说明滚轮已不再被捕获。

**当滚轮“不再”被捕获时，会发生什么？**

届时，Mac Mouse Fix 将完全忽略你的滚轮——在滚动期间，它不会消耗任何处理器性能或电池电量，也不会产生任何干扰。这让你能够完全自由地使用其他应用（如 [MOS](https://mos.caldis.me/)）来接管和处理你的滚轮。
