Mac Mouse Fixは、お使いのマウスをより快適にするアプリです。

私は、Mac Mouse Fixを**史上最高**のマウスドライバーにしたいと考えています！現時点ではまだ足りない機能もありますが、いくつかの点においては、すでに**普通のマウスをMacにとって最高の入力デバイスへと進化させている**と自負しています。それは、AppleのトラックパッドやLogitech（ロジクール）のMX Masterマウスと同等、あるいはそれ以上の体験です。

Mac Mouse Fixがどのようにマウスを強化するのか、より詳しい情報は[ウェブサイト](https://macmousefix.com/)をご覧ください。

<a name="installation"></a>
##インストール
Mac Mouse Fixの最新バージョンは、[ウェブサイト](https://macmousefix.com/)からダウンロードできます。

また、[Homebrew](https://brew.sh/) を使ってインストールすることもできます！ ターミナルに以下のコマンドを入力してください：

```bash
brew install mac-mouse-fix
```

以前のバージョンのMac Mouse Fixは、[リリース](https://github.com/noah-nuebling/mac-mouse-fix/releases)からダウンロードいただけます。

<a name="macos-compatibility"></a>
##macOSの互換性
Mac Mouse Fixの最新バージョンは、macOS 11 Big Sur以降に対応しています。

macOS 10.15 Catalina、macOS 10.14 Mojave、または macOS 10.13 High Sierraをご利用の場合は、[Mac Mouse Fix 2 の最新バージョン](https://redirect.macmousefix.com/?locale=ja&target=mmf2-latest)をお使いいただけます。Mac Mouse Fix 3.0.0以降も動作する可能性はありますが、画面表示の不具合や一部の機能が正しく動作しない場合があります。

macOS 10.12 SierraまたはmacOS 10.11 El Capitanをご利用の場合は、Mac Mouse Fix [2.2.0](https://github.com/noah-nuebling/mac-mouse-fix/releases/tag/2.2.0)以前のバージョンをお使いいただけます。

<a name="uninstallation"></a> 
##アンインストール

Mac Mouse Fixをアンインストールするには、アプリをゴミ箱へ移動するだけです。

ただし、その場合はシステム内に関連ファイルが残ります。これらのファイルを完全に削除するには、非常に便利なツールである[FreeMacSoft の AppCleaner](https://freemacsoft.net/appcleaner/)の使用をお勧めします。

macOS の仕様上、アプリを削除した際に、そのアプリ自身が残存ファイルを削除することはできません。そのため、AppCleanerのようなアプリの使用を強くお勧めしています。

<a name="tips"></a> 
## ヒント

- **クリックしてドラッグするだけ！ウィンドウを簡単に整理**

  [Swish](https://highlyopinionated.co/swish/)は、macOSでウィンドウを管理するツールとして、私の一押しのアプリです。トラックパッドをスワイプするだけで、ウィンドウを画面の半分、4分の1、または全画面に素早く配置できます。
  
  Swishは本来トラックパッドのジェスチャ向けに設計されていますが、Mac Mouse Fixを使えば、一般的なサードパーティ製マウスでも同じように操作可能です！Mac Mouse Fixの設定で、任意のボタンの'クリックとドラッグ'アクションを'スクロールとナビゲート'に設定するだけで、簡単なクリックとドラッグでウィンドウをスナップできるようになります。
  
  Appleのトラックパッドでの2本指スワイプで行える操作はすべて、Mac Mouse Fixの'スクロールとナビゲート'機能でも同様に快適に動作します

- **画面の明るさ、音量、メディア再生をマウスから直接コントロール**

  Mac Mouse Fixを使えば、**キーボードのあらゆるキー**をマウスから直接操作できます。
  画面の明るさ、音量、メディア再生などをコントロールする、Appleキーボード特有の特殊キーも例外ではありません。
  
  手元に Appleキーボードがない場合は、**Option (⌥) **を押しながら選択することで、これらの特殊なAppleキーを指定できるようになります。

<a name="questions"></a> 
## よくある質問

- Mac Mouse FixはAppleシリコンにネイティブ対応していますか？
    
  はい。Mac Mouse Fixは、Appleシリコン上で100%ネイティブに動作します。

- **クリックしたときに遅延（タイムラグ）が発生するのはなぜですか？**

  クリックした際、Mac Mouse Fixはダブルクリックが行われるかどうかを判別するために待機することがあります。<br>
  特定のボタンの遅延を解消するには、そのボタンに割り当てられている'ダブルクリック'アクションをすべて削除してください。

- **自分のマウスは対応していますか？
**

  おそらく大丈夫です。確実に知りたい場合は、Mac Mouse Fixをダウンロードして実際に試してみるのが一番です。
  
  Mac Mouse Fixは、ほとんどのマウスで非常に快適に動作します。ただし、Logitech Optionsなどの独自のドライバーソフトウェアでの使用を前提とした特定のマウスでは、現時点ではすべてのボタンを認識できない場合があります。
  
  これは、これらのマウスが標準的な USBプロトコルではなく、メーカー独自の特殊なプロトコルを使用してコンピュータと通信しているためです。<br>
  将来的にはこれらのマウスにも完全に対応したいと考えていますが、膨大な作業が必要になるため、すぐの実現は難しい状況です。

- **開発を支援する**
  
  私は Mac Mouse Fixを通じて経済的に自立することを目指しています。そうすることで、今後もアプリの改善や開発に専念し続けることができます。もし活動を支援していただけるなら、以下の方法があります：
  1.アプリ内のボタン、または[こちら](https://noahnuebling.gumroad.com/l/mmfinappusd)をクリックしてMac Mouse Fixを購入する。
