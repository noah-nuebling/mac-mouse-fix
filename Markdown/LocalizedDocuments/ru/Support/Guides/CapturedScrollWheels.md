# Захваченные колеса прокрутки

Mac Mouse Fix **по умолчанию захватывает колесико прокрутки мыши**, аналогично тому, как он [захватывает кнопки мыши](<../../Support/Guides/CapturedButtonsMMF3.md>).

**Чтобы предотвратить захват колесика прокрутки:**

1. Перейдите на вкладку «Прокрутка» в Mac Mouse Fix
2. Отключите **все** опции
- В случае опции «Скорость» установите значение «macOS»
- Удалите все записи в разделе «Модификаторы клавиатуры», нажав кнопку «x» рядом с каждым модификатором

После этого вы должны увидеть сообщение о том, что колесико прокрутки больше не захватывается.

**Что происходит, когда колесико прокрутки *больше* не захватывается?**

Mac Mouse Fix полностью игнорирует ваше колесико прокрутки — оно не будет использовать ресурсы процессора или заряд батареи во время прокрутки и не будет мешать вам никоим образом. Это дает вам полную свободу использовать другие приложения, такие как [MOS](https://mos.caldis.me/), для управления колесиком прокрутки.
