<a name="installation"></a>
## Установка

Загрузите последнюю версию Mac Mouse Fix на [веб-сайте](https://macmousefix.com/).

Вы также можете установить Mac Mouse Fix через [Homebrew](https://brew.sh/)! Просто введите следующую команду в терминале:

```bash
brew install mac-mouse-fix
```

Вы можете загрузить более старые версии Mac Mouse Fix в разделе [Релизы](https://github.com/noah-nuebling/mac-mouse-fix/releases).

<a name="macos-compatibility"></a>
## Совместимость с macOS

Последняя версия Mac Mouse Fix разработана для **macOS 11 Big Sur** или более поздних версий.
  
Если вы используете macOS **10.15 Catalina**, macOS **10.14 Mojave** или macOS **10.13 High Sierra**, вы можете использовать [последнюю версию Mac Mouse Fix 2](https://redirect.macmousefix.com/?locale=ru&target=mmf2-latest). Mac Mouse Fix 3.0.0 и более поздние версии могут по-прежнему работать на вашем компьютере, но у них будут проблемы с отображением, и некоторые функции могут работать некорректно.
    
Если вы используете macOS **10.12 Sierra** или **10.11 El Capitan**, вы можете использовать Mac Mouse Fix [2.2.0](https://github.com/noah-nuebling/mac-mouse-fix/releases/tag/2.2.0) или более раннюю версию.

<a name="uninstallation"></a> 
## Удаление

Удалите Mac Mouse Fix, просто переместив его в корзину. 

Однако в вашей системе останутся файлы. Чтобы избавиться от этих файлов, я рекомендую отличную программу [AppCleaner от FreeMacSoft](https://freemacsoft.net/appcleaner/).

В macOS приложения не могут самостоятельно удалять эти оставшиеся файлы при удалении приложения. Поэтому я настоятельно рекомендую использовать такое приложение, как AppCleaner.

<a name="tips"></a> 
## Подсказки

- **Управляйте окнами простым нажатием и перетаскиванием**

  [Swish](https://highlyopinionated.co/swish/) — мой любимый способ управления окнами в macOS. Простым движением по трекпаду вы можете расположить любое окно так, чтобы оно занимало половину, четверть или весь экран.
  
  Swish разработан для жестов трекпада, но с помощью Mac Mouse Fix вы можете использовать его с любой сторонней мышью! Просто перейдите в Mac Mouse Fix и установите для любой кнопки действие «Щелкнуть и перетащить» на «Прокрутка и навигация», после чего вы сможете привязывать окна простым щелчком и перетаскиванием.
  
  Все, что можно сделать с помощью двухпальцевого жеста на трекпаде Apple, так же хорошо работает с функцией 'Прокрутка и навигация' в Mac Mouse Fix.

- **Управляйте яркостью экрана, громкостью звука или воспроизведением мультимедиа прямо с помощью мыши**

  Mac Mouse Fix позволяет использовать **любую клавишу на клавиатуре** прямо с мыши -
  даже специальные клавиши, которые есть только на клавиатурах Apple и позволяют регулировать яркость экрана, громкость звука, воспроизведение мультимедиа и многое другое.
  
  Если у вас нет клавиатуры Apple, **удерживайте клавишу Option (⌥)**, чтобы выбрать специальные клавиши Apple.

<a name="questions"></a> 
## Вопросы

- **Является ли Mac Mouse Fix нативным приложением для Apple Silicon?**
    
  Да, Mac Mouse Fix работает на 100% на Apple Silicon.

- **Почему при нажатии кнопки возникает задержка?**

  Когда вы нажимаете кнопку, Mac Mouse Fix может подождать, чтобы увидеть, собираетесь ли вы сделать двойное нажатие.
  Чтобы устранить задержку для кнопки, удалите все действия «Двойного нажатия» для этой кнопки.

  - Включите «Показать в строке меню»

- **Поддерживается ли моя мышь?**

  Вероятно. Если вы хотите узнать наверняка, лучше всего скачать Mac Mouse Fix и попробовать его.
  
  Mac Mouse Fix отлично работает с большинством мышей. Однако на некоторых мышах, предназначенных для использования с проприетарным драйвером, таким как Logitech Options, Mac Mouse Fix в настоящее время не может распознать все кнопки. 
  
  Это связано с тем, что эти мыши обмениваются данными с компьютером по специальному проприетарному протоколу, а не по стандартному протоколу USB.
  Я бы с удовольствием добавил полную совместимость с этими мышами, но это огромный объем работы, и в ближайшее время это не произойдет.

- **Некоторые кнопки на моей мыши не распознаются**

  См. вопрос **«Поддерживается ли моя мышь?»** выше.
