<a name="installation"></a>
## Instalación

Descarga la última versión de Mac Mouse Fix en el [sitio web](https://macmousefix.com/).

¡También puedes instalar Mac Mouse Fix a través de [Homebrew](https://brew.sh/)! Simplemente escribe el siguiente comando en el terminal:

```bash
brew install mac-mouse-fix
```

Puedes descargar versiones anteriores de Mac Mouse Fix en [Lanzamientos](https://github.com/noah-nuebling/mac-mouse-fix/releases).

<a name="macos-compatibility"></a>
## Compatibilidad con macOS

La última versión de Mac Mouse Fix está diseñada para **macOS 11 Big Sur** o posterior.

Si utilizas **macOS 10.15 Catalina**, **macOS 10.14 Mojave** o **macOS 10.13 High Sierra**, puedes usar la [última versión de Mac Mouse Fix 2](https://redirect.macmousefix.com/?locale=es&target=mmf2-latest). Mac Mouse Fix 3.0.0 y versiones posteriores podrían seguir funcionando en tu máquina, pero tendrán problemas visuales y es posible que algunas funciones no funcionen correctamente.

Si utilizas **macOS 10.12 Sierra** o **10.11 El Capitan**, puedes usar Mac Mouse Fix [2.2.0](https://github.com/noah-nuebling/mac-mouse-fix/releases/tag/2.2.0) o anterior.

<a name="uninstallation"></a> 
## Desinstalación

Desinstala Mac Mouse Fix simplemente moviéndolo a la papelera.

Sin embargo, quedarán archivos en tu sistema. Para deshacerte de estos archivos, recomiendo la impresionante aplicación [AppCleaner de FreeMacSoft](https://freemacsoft.net/appcleaner/).

En macOS, no es factible que las aplicaciones eliminen estos archivos sobrantes por sí mismas al eliminarlas. Por eso recomiendo encarecidamente utilizar una aplicación como AppCleaner.

<a name="tips"></a> 
## Consejos

- **Gestiona ventanas con un simple Clic y arrastrar**

  [Swish](https://highlyopinionated.co/swish/) es mi forma favorita de gestionar ventanas en macOS. Con un simple deslizamiento en tu trackpad, te permite colocar cualquier ventana para que ocupe la mitad, un cuarto o toda la pantalla.
  
  Swish está diseñado para gestos de trackpad, ¡pero con Mac Mouse Fix puedes usarlo desde cualquier ratón de terceros! Simplemente ve a Mac Mouse Fix y configura la acción "Clic y Arrastrar" de cualquier botón en "Desplazamiento y Navegación" y luego podrás ajustar ventanas con un simple Clic y arrastrar.
  
  Cualquier cosa que puedas hacer con un deslizamiento de dos dedos en un trackpad de Apple funciona igual de bien con la función "Desplazamiento y navegación" de Mac Mouse Fix.

- **Controla el brillo de la pantalla, el volumen del audio o la reproducción multimedia directamente desde el ratón**

  Mac Mouse Fix te permite usar **cualquier tecla de tu teclado** directamente desde el ratón, incluso teclas especiales que solo se encuentran en los teclados de Apple y que te permiten controlar el brillo de la pantalla, el Volumen del Audio, la Reproducción Multimedia y más.
  
  Si no tienes un teclado de Apple a mano, **mantén pulsada Opción (⌥)** para elegir las teclas especiales de Apple.

<a name="questions"></a> 
## Preguntas

- **¿Es Mac Mouse Fix nativo en Apple Silicon?**
    
  Sí, Mac Mouse Fix se ejecuta 100% de forma nativa en Apple Silicon.

- **¿Por qué hay un retraso cuando hago clic?**

  Cuando haces clic, Mac Mouse Fix podría esperar para ver si vas a hacer doble clic.<br>
  Para eliminar el retraso de un botón, elimina cualquier acción de "Doble Clic" para ese botón.

- **¿Es compatible mi ratón?**

  Probablemente. Si quieres saberlo con seguridad, lo mejor es descargar Mac Mouse Fix y probarlo.
  
  Mac Mouse Fix funciona muy bien con la mayoría de los ratones. Sin embargo, en ciertos ratones diseñados para usarse con software de controlador propietario como Logitech Options, Mac Mouse Fix no puede reconocer todos los botones en este momento.
  
  Esto se debe a que estos ratones se comunican con tu ordenador utilizando un protocolo especial y propietario, en lugar del protocolo USB estándar.<br>
  Me encantaría añadir compatibilidad total para estos ratones en algún momento, pero es muchísimo trabajo y no será pronto.

- **Algunos botones de mi ratón no son reconocidos**

  Consulta la pregunta **"¿Es compatible mi ratón?"** más arriba.

- **¿Es compatible el Magic Mouse?**

  Es posible que añada funciones en el futuro que mejoren el Apple Magic Mouse, pero actualmente, Mac Mouse Fix no tiene ningún efecto en él.
