<a name="installation"></a>
## Встановлення

Завантажте останню версію Mac Mouse Fix на [вебсайті](https://macmousefix.com/).

Ви також можете встановити Mac Mouse Fix через [Homebrew](https://brew.sh/)! Просто введіть таку команду в терміналі:

```bash
brew install mac-mouse-fix
```

Ви можете завантажити старіші версії Mac Mouse Fix у розділі [Випуски](https://github.com/noah-nuebling/mac-mouse-fix/releases).

<a name="macos-compatibility"></a>
## Сумісність з macOS

Остання версія Mac Mouse Fix створена для **macOS 11 Big Sur** або новішої версії.

Якщо ви використовуєте macOS **10.15 Catalina**, macOS **10.14 Mojave** або macOS **10.13 High Sierra**, ви можете використовувати [останню версію Mac Mouse Fix 2](https://redirect.macmousefix.com/?locale=uk&target=mmf2-latest). Mac Mouse Fix 3.0.0 і новіші версії все ще можуть працювати на вашому комп’ютері, але матимуть візуальні проблеми, а деякі функції можуть працювати некоректно.

Якщо ви використовуєте macOS **10.12 Sierra** або **10.11 El Capitan**, ви можете використовувати Mac Mouse Fix [2.2.0](https://github.com/noah-nuebling/mac-mouse-fix/releases/tag/2.2.0) або ранішої версії.

<a name="uninstallation"></a> 
## Видалення

Видаліть Mac Mouse Fix, просто перемістивши його в Смітник.

Однак у вашій системі залишаться файли. Щоб позбутися цих файлів, я рекомендую чудову програму [AppCleaner від FreeMacSoft](https://freemacsoft.net/appcleaner/).

У macOS програми не можуть самостійно видаляти ці залишкові файли під час видалення програми. Тому я наполегливо рекомендую використовувати таку програму, як AppCleaner.

<a name="tips"></a> 
## Поради

- **Керуйте вікнами просто за допомогою Клацання та Перетягування**

  [Swish](https://highlyopinionated.co/swish/) – мій улюблений спосіб керування вікнами в macOS. Простим проведенням по трекпеду ви можете розмістити будь-яке вікно на половину, чверть або весь екран.
  
  Swish створено для жестів трекпеда, але з Mac Mouse Fix його можна використовувати з будь-якою мишею!Просто призначте для будь-якої кнопки дію 'Клацання та Перетягування' на функцію 'Прокрутка та Навігація' і ви зможете миттєво прикріплювати вікна.
  
  Усе, що можна зробити проведенням двома пальцями по трекпеду Apple, так само добре працює з функцією 'Прокрутка та Навігація' в Mac Mouse Fix.

- **Керуйте яскравістю екрана, гучністю звуку або відтворенням мультимедіа прямо з миші**

  Mac Mouse Fix дозволяє використовувати **будь-яку клавішу на клавіатурі** безпосередньо з миші — навіть спеціальні клавіші, які є лише на клавіатурах Apple, що дозволяють керувати яскравістю екрана, гучністю звуку, відтворенням мультимедіа та іншим.
  
  Якщо у вас під рукою немає клавіатури Apple, **утримуйте Option (⌥)**, щоб вибрати спеціальні клавіші Apple.

- **Чи існують 'Налаштування для окремих програм' або 'Профілі'?**

- **Чи підтримується моя миша?**

  Скоріш за все так. Якщо ви сумніваєтесь, завантажте Mac Mouse Fix безкоштовно і перевірте.
  
  Mac Mouse Fix працює файно з більшістю мишок. Однак на певних мишках, призначених для використання з стороннім програмним забезпеченням для драйверів (наприклад Logitech Options), Mac Mouse Fix може не розпізнати всі клавіші. 
  
  Це тому, що ці мишки спілкуються з комп'ютером за допомогою спеціального, власного протоколу замість стандартного протоколу USB.<br>
  Я хотів би додати повну сумісність для цих мишей в якийсь момент, але то є вагон роботи, тому не скоро з'явиться.
