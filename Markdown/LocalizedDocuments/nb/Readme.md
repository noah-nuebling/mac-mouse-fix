Mac Mouse Fix er en app som gjør musen din bedre.

Jeg vil gjøre Mac Mouse Fix til den beste musedriveren *gjennom tidene*! Noen funksjoner mangler fortsatt for øyeblikket, men jeg tror den allerede **gjør vanlige muser til de beste inndataenhetene for Mac** på noen måter. På samme nivå, eller enda bedre, enn en Apple Trackpad eller en Logitech MX Master-mus.

For mer informasjon om hvordan Mac Mouse Fix forbedrer musen din, besøk [nettstedet](https://macmousefix.com/).

<a name="installation"></a>
## Installasjon

Last ned den nyeste versjonen av Mac Mouse Fix på [nettstedet](https://macmousefix.com/).

Du kan også installere Mac Mouse Fix via [Homebrew](https://brew.sh/)! Bare skriv inn følgende kommando i terminalen:

```bash
brew install mac-mouse-fix
```

Du kan laste ned eldre versjoner av Mac Mouse Fix under [Utgivelser](https://github.com/noah-nuebling/mac-mouse-fix/releases).

<a name="macos-compatibility"></a>
## macOS-kompatibilitet

Den nyeste versjonen av Mac Mouse Fix er laget for **macOS 11 Big Sur** eller nyere.

Hvis du bruker macOS **10.15 Catalina**, macOS **10.14 Mojave** eller macOS **10.13 High Sierra**, kan du bruke [nyeste versjon av Mac Mouse Fix 2](https://redirect.macmousefix.com/?locale=nb&target=mmf2-latest). Mac Mouse Fix 3.0.0 og nyere kan fortsatt fungere på maskinen din, men de vil ha visuelle problemer, og noen funksjoner fungerer kanskje ikke som de skal.

Hvis du bruker macOS **10.12 Sierra** eller **10.11 El Capitan**, kan du bruke Mac Mouse Fix [2.2.0](https://github.com/noah-nuebling/mac-mouse-fix/releases/tag/2.2.0) eller eldre.

<a name="tips"></a> 
## Tips

- **Administrer vinduer med et enkelt klikk og dra**

  [Swish](https://highlyopinionated.co/swish/) er min favorittmåte å administrere vinduer på macOS. Med et enkelt sveip på styreflaten kan du plassere et hvilket som helst vindu slik at det tar opp halvparten, en fjerdedel eller hele skjermen.
  
  Swish er designet for styreflatebevegelser, men med Mac Mouse Fix kan du bruke det fra en hvilken som helst tredjepartsmus! Bare gå til Mac Mouse Fix og sett en hvilken som helst knapps «Klikk og dra»-handling til «Bla og naviger», så kan du feste vinduer med et enkelt klikk og dra.
  
  Alt du kan gjøre med et sveip med to fingre på en Apple-styreflate fungerer like bra med «Bla og naviger»-funksjonen i Mac Mouse Fix.

- **Styr skjermens lysstyrke, lydvolum eller medieavspilling direkte fra musen**

  Med Mac Mouse Fix kan du bruke **hvilken som helst tast på tastaturet** direkte fra musen –
  til og med spesialtaster som bare finnes på Apple-tastaturer, og som lar deg kontrollere skjermens lysstyrke, lydvolum, medieavspilling og mer.
  
  Hvis du ikke har et Apple-tastatur for hånden, **holder du inne option (⌥)** for å velge de spesielle Apple-tastene.

- **Er Mac Mouse Fix støttet på Apple Silicon?**
    
  Ja, Mac Mouse Fix kjører 100 % på Apple Silicon.

- **Hvorfor er det en forsinkelse når jeg klikker?**

  Når du klikker, kan det hende at Mac Mouse Fix venter for å se om du skal dobbeltklikke.<br>
  For å fjerne forsinkelsen for en knapp, slett eventuelle «Dobbeltklikk»-handlinger for den knappen.

- **Støttes musen min?**

  Sannsynligvis. Hvis du vil vite det sikkert, er det best å laste ned Mac Mouse Fix og prøve det ut.
  
  Mac Mouse Fix fungerer veldig bra med de fleste mus. På visse mus som er designet for bruk med proprietær driverprogramvare, som Logitech Options, kan imidlertid ikke Mac Mouse Fix gjenkjenne alle knappene for øyeblikket.
  
  Det er fordi disse musene kommuniserer med datamaskinen din ved hjelp av en spesiell, proprietær protokoll, i stedet for standard USB-protokoll.<br>
  Jeg skulle gjerne lagt til full kompatibilitet for disse musene på et tidspunkt, men det er mye arbeid, og det kommer ikke med det første.

- **Noen knapper på musen min gjenkjennes ikke**

  Se spørsmålet **'Støttes musen min?'** ovenfor.

- **Støttes Magic Mouse?**

  Jeg kan legge til funksjoner i fremtiden som forbedrer Apple Magic Mouse, men for øyeblikket har Mac Mouse Fix ingen effekt på den.

  Hvis du vil **hjelpe med å oversette prosjektet**, kan du se [oversettelsesveiledningen](https://redirect.macmousefix.com/?target=mmf-localization-contribution).<br>
  Hvis du vil **rapportere manglende eller suboptimale oversettelser**, er det også veldig nyttig. Den beste måten å rapportere problemer på er ved å kommentere under [Oversettelsesveiledningen](https://redirect.macmousefix.com/?target=mmf-localization-contribution).
